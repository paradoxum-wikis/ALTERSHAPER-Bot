# Aphonos

**Aphonos**, formerly **ALTERSHAPER**, is a utility Discord bot made specifically for ALTER EGO Wiki and Tower Defense Simulator Wiki.

Although one could use this bot anywhere else, due to it being developed mainly for the two wikis previously mentioned, it is extremely opinionated and suffers from hardcoded variables, especially in behaviors that depend on an external service that we also host.

Notable features include our own moderation system, minigames such as deathbattle or russian roulette, MediaWiki integrations such as account verification and LLM agent jobs.
